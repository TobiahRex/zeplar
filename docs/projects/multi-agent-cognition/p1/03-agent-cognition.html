💡 Infrastructure Design Principles

1. Namespace Isolation: Each tenant gets a dedicated K8s namespace with ResourceQuotas and NetworkPolicies preventing cross-tenant traffic.

2. Connection Pooling: PgBouncer in transaction mode limits DB connections to ~20 per pod regardless of agent count.

3. Message Durability: NATS JetStream provides at-least-once delivery with consumer acknowledgment and replay capability.

4. Secrets Rotation: Vault dynamically generates DB credentials with 1-hour TTL; agents refresh on expiry.

5. Zero-Trust Network: Istio enforces mTLS between all services; no plaintext traffic within the mesh.
