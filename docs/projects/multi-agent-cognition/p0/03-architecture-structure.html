Layer 1: Structural Architecture — The Static Topology

📖 Lexicon — Core Terminology

Tenant (T)
An isolated customer environment with dedicated resources, data, and configuration boundaries.
Org Chart Instance (OCI)
A single hierarchical agent graph representing one workflow execution unit.
Agent Role (AR)
Human-proxy archetype (CEO, Architect, Engineer, Intern) defining capabilities and authority.
Agent Instance (AI)
A runtime instantiation of an Agent Role with state, context, and active tasks.
Task Graph (TG)
DAG of work items flowing through agent hierarchy with dependencies.
Event Bus (EB)
Internal pub/sub backbone for DB notifications and system events.
WebSocket Bridge (WSB)
Protocol adapter translating internal events to client-consumable streams.
Checkpoint (CP)
Durable state snapshot enabling workflow resumption after interruption.

🎯 Key Structural Insights

1. Tenant Isolation: Each tenant has dedicated DB, Event Bus, and Agent Pool — no cross-tenant data leakage.

2. Instance Multiplexing: Single WebSocket can fan-out to multiple Org Chart Instances via Message Router.

3. Hierarchical Authority: Parent agents can only task children; verification flows upward.

4. State Durability: Every state transition creates a checkpoint for workflow recovery.
