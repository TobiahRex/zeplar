🎨 Health Score → Color Mapping
flowchart LR subgraph INPUT["📥 Module Metrics"] A["error_rate"] B["blocked_paths"] C["latency_p99"] end subgraph CALC["🧮 Health Calculation"] D["error_penalty = error_rate × 50"] E["block_penalty = blocked × 20"] F["latency_penalty = (p99 > 500ms) × 10"] G["health = 100 - penalties"] end subgraph COLOR["🎨 Color Scale"] H["90-100%: Deep Green"] I["70-89%: Light Green"] J["50-69%: Yellow"] K["30-49%: Orange"] L["0-29%: Red"] end A --> D B --> E C --> F D & E & F --> G G --> H & I & J & K & L
health_score = 100 - (error_rate × 50) - (blocked_paths × 20) - latency_penalty

with LOC values"] end subgraph SORT["📊 Sort"] B["Sort by LOC descending"] C["Largest features first"] end subgraph SQUARIFY["📐 Squarify Algorithm"] D["Calculate aspect ratios"] E["Subdivide rectangles"] F["Minimize elongation"] end subgraph RENDER["🎨 Render"] G["Apply health colors"] H["Add labels"] I["Enable interactions"] end A --> B --> C --> D --> E --> F --> G --> H --> I style F fill:#1a1a2e,stroke:#00d9ff,color:#fff

Size = Code Footprint

Box area is proportional to lines of code. Larger boxes represent more code, which means higher priority when health degrades.

Color = Health

Green (100%) → Red (0%) gradient shows function call success rate. At a glance, you see where the problems are concentrated.

🎯 Each View Answers Different Questions

🕐 Rings → Velocity

"Are my AI agents productive right now? What's slowing them down?"

🕸️ Graph → Topology

"How does the code flow? Where are the connections broken?"

🗺️ Treemap → Proportion

"Where is the most code? Where should I focus remediation?"

🔗 Combined → Action

"This agent (ring) is blocked because this path (graph) in this large module (treemap) is broken."
