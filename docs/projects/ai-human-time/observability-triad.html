Core Formulas

🕐 Ring Velocity

velocity = base_rate × (1 - impedance)

🕸️ Edge Health

status = f(error_rate, latency, staleness)

🗺️ Module Health

health = 100 - Σ(penalties)

💡 The Combined Insight

Each system answers different questions. Together, they enable root-cause analysis:

"This agent (ring) is blocked because this path (graph) in this large module (treemap) is broken."

The human observer can: (1) See velocity drop in Rings → (2) Trace broken path in Graph → (3) Prioritize by code mass in Treemap → (4) Take targeted action.
